# WannaShop Inventario · versión web

Inventario para una bodega de zapatos que distribuye a negocios asociados en consignación:
modelos con todas sus tallas, despachos, cierre del día, facturas, cobros, caja, gastos y asistente IA.

- **Abrir la app:** https://wanna033.github.io/wannashop/
- Se entra con una cuenta de Google. Solo pueden entrar los correos que el administrador autorice.
- Los datos y las fotos se guardan en la nube (Firebase) y se ven al instante en todos los equipos.
- En el celular se puede instalar como app: menú del navegador → «Agregar a la pantalla principal».

Este repositorio contiene solo la página ya construida.
